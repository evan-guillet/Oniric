# Recette v0.1 alpha

Critères de sortie (PRD, 13) : parcours P1 et P5 réussis, test de coupure 1000 fois sans corruption, PDF conforme sur 5 scénarios de référence. Les contrôles automatiques sont rejoués par `npm run e2e` et le test de coupure ; les contrôles manuels se font sur une machine virtuelle Windows 10 neuve (22H2, WebView2 tel que livré, compte non administrateur).

## Automatique

| Contrôle | Commande | Résultat attendu |
|---|---|---|
| Règles TypeScript | `npm test` | Tout passe |
| Cœur Rust | `cargo test -p oniric -p oniric-crash-test --no-default-features` | Tout passe |
| Coupures | `cargo run --release -p oniric-crash-test -- lancer --iterations 1000` | « aucune corruption, aucun lot validé perdu » |
| P1, P5, PDF, mesures | `npm run e2e -- <chemin de Oniric.exe>` | Tous les contrôles OK ; résultats dans `tests/e2e/resultats/` |

## Manuel, sur Windows 10 neuf

### Installation
- [ ] L'installateur fait moins de 15 Mo et s'installe sans droits d'administrateur.
- [ ] SmartScreen avertit (installateur non signé) ; l'installation se termine après « Exécuter quand même ».
- [ ] Oniric apparaît dans le menu Démarrer, démarre en moins de 3 s, sans connexion réseau.

### P1 — Premier scénario
- [ ] Nouveau projet « Essai » au format français, dans Documents : le dossier contient `projet.oniric`, `donnees.db`, `exports`, `medias`, `versions`.
- [ ] Écrire trois scènes avec `Entrée` et `Tab` seulement : en-tête, action, personnage, dialogue, parenthèse, transition s'enchaînent sans souris.
- [ ] `int. cuisine - jour` s'affiche en majuscules et la scène apparaît dans la liste ; `Tu pars ?` reçoit une espace insécable.
- [ ] La liste des scènes suit la frappe ; un clic y mène à la scène.
- [ ] Les sauts de page apparaissent dans l'éditeur, avec `(SUITE)` et `(À SUIVRE)` dans un dialogue coupé.
- [ ] `Ctrl+P` : le PDF dans `exports` a les mêmes pages que l'écran, en Courier Prime 12, sur A4.
- [ ] Même essai au format américain : Letter, `(MORE)` et `(CONT'D)`.
- [ ] Fermer, rouvrir depuis « Projets récents » : tout est là. Double-cliquer sur `projet.oniric` : le projet s'ouvre.

### P5 — Plantage
- [ ] Taper une phrase, attendre 2 s, tuer Oniric depuis le Gestionnaire des tâches. Au redémarrage, Oniric propose de récupérer ; « Récupérer » rend la phrase.
- [ ] Même chose avec « Repartir du dossier » : la phrase a disparu, le reste est intact.
- [ ] Couper l'alimentation de la machine virtuelle pendant la frappe : au redémarrage, rien de plus que les dernières secondes n'est perdu.

### Désinstallation
- [ ] Désinstaller sans cocher « supprimer les données » : les projets et les copies de travail restent.
